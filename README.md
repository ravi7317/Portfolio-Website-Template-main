## 🎨 Visual Preview & Design Highlights

The website features a premium, dark-themed user interface with sleek HSL-tailored colors, high-impact glassmorphic design elements, and interactive animations:

*   **Glowing Profile Avatar:** Built with CSS gradient borders and pulse animations to draw attention and feel premium.
*   **Live Status Indicator:** A dynamic pulsing green badge signifying current work availability.
*   **Typing Animation:** A smooth typing effect in the hero section to present skills dynamically.
*   **Project Cards Zoom Effect:** Subtle micro-animations on project cards for an engaging browsing experience.

## 🛠️ Built With

This portfolio is crafted using modern, clean front-end technologies optimized for performance and visual fidelity:

*   **Structure:** HTML5 (Semantic elements for SEO optimization)
*   **Styling & Layout:** Vanilla CSS3, Bootstrap 4, and Google Fonts (Poppins)
*   **Animations:** [Animate.css](https://animate.style/), [AOS (Animate on Scroll)](https://michalsnik.github.io/aos/), and custom CSS transitions
*   **Interactions:** JavaScript (ES6+), jQuery, Owl Carousel (for sliders), and Magnific Popup

## 💻 Local Setup & Development

To run this project locally, follow these simple steps:

### Option 1: Direct Execution
Simply clone the repository and open the `index.html` file in any modern web browser:
```bash
# Clone the repository
git clone https://github.com/ravi7317/portfolio-website-ravi.git

# Navigate to the folder
cd portfolio-website-ravi

# Open index.html (Double-click the file, or open with browser)
```

### Option 2: Local HTTP Server (Recommended)
Running through an HTTP server ensures correct loading of local file protocols and web assets:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (serve package)
npx serve .
```
Then open your browser and navigate to `http://localhost:8000` (or the port specified by serve).
